Scala 2D Physics Engine

This project is a lightweight 2D physics engine written in Scala. Originally developed as an educational and exploratory project, it implements particle-based mechanics, spring systems, and constraint handling, with real-time rendering for interactive demos. I recently revived and modernized the codebase, creating new example scenes and a video showcase.

Technical highlights

  • Particle & rigid body simulation: simple but extensible framework for 2D motion.
  • Springs & constraints: support for pinning, elastic connections, and composite structures.
  • Numerical integration: Euler and Verlet-style integrators for stable motion.
  • Collision behavior: basic collision detection and response between particles/objects.
  • Interactive demos: pendulums, bridges, cloth-like structures, and elastic assemblies.
  • Scala design: functional/OO mix, modular code structure for experimentation.

The engine was primarily built as a playground for experimenting with physics modeling in a high-level JVM language, while keeping the architecture accessible for educational use and small demos.

Role: Contributed to multiple aspects including graphics, constraint modeling (elastic, stiff, and pinned connections), and collision handling.
